Set up the Shortcut

Build a Shortcut named SyncHealth. When you tap Sync above, the app launches it and passes your token automatically as the Shortcut Input — you never paste it. The Shortcut POSTs your data to the backend; the app then reloads it.

Steps:

  1. 1 Find Health Samples → Sample Type Steps, filter Start Date is today.
  2. 2 Calculate Statistics → operation Sum.
  3. 3 Get Contents of URL → Method POST, URL {{ postUrl }}, Header Content-Type: application/json.
  4. 4 Request Body JSON with fields: token = Shortcut Input, steps = the Statistics number.
  5. 5 Name the Shortcut exactly SyncHealth.

Each run upserts today’s steps; the daily chart builds up over time.

Runs (add to the same request):

  1. a Find Workouts → filter Type is Running, Limit 10, sort by End Date (newest).
  2. b Repeat with Each workout → build a Dictionary per run with keys date (Start Date, yyyy-MM-dd), distanceKm, durationMin, calories, avgHr. Add each dictionary to a list (Add to Variable Runs).
  3. c In the JSON body add a field runs (Array) = the Runs list.

Distance in km, duration in minutes. Pace is computed here. Cadence / per-km splits / route aren’t available via Shortcuts — those need a native HealthKit app.

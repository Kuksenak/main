Set up the Shortcut

Build a Shortcut named SyncHealth. Paste your token into it once (below) — that literal is used for background automations. When you tap Sync in the app, it also passes the token as the Shortcut Input, which overrides the literal. So the same Shortcut works both ways.

@if (health.token(); as token) {
Your sync token
{{ token }}
Paste this into the Shortcut’s Text action (step 1). It’s the fallback for background runs; launching from the app overrides it via the Shortcut Input.
}

Steps:

  1. 1 Text → paste your token (from the box above). This is the fallback for background runs.
  2. 2 If → set the condition input to Shortcut Input, condition has any value.
    • Set Variable Token to Shortcut Input.
    • Otherwise → Set Variable Token to the Text from step 1.
  3. 3 Find Health Samples → Sample Type Steps, filter Start Date is today.
  4. 4 Calculate Statistics → operation Sum.
  5. 5 Get Contents of URL → Method POST, URL {{ postUrl }}, Header Content-Type: application/json.
  6. 6 Request Body JSON with fields: token = the Token variable, steps = the Statistics number.
  7. 7 Name the Shortcut exactly SyncHealth.

Each run upserts today’s steps; the daily chart builds up over time.

Runs (add to the same request):

  1. a Find Workouts → filter Type is Running, Limit 10, sort by End Date (newest).
  2. b Repeat with Each workout → build a Dictionary per run with keys date (Start Date, yyyy-MM-dd), distanceKm, durationMin, calories, avgHr. Add each dictionary to a list (Add to Variable Runs).
  3. c In the JSON body add a field runs (Array) = the Runs list.

Distance in km, duration in minutes. Pace is computed here. Cadence / per-km splits / route aren’t available via Shortcuts — those need a native HealthKit app.

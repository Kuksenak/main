Steps by day

Set up the Shortcut

Reads steps from the Health app and reopens this app with them. No native app, no account.

@if (shortcutReady) { Add to Shortcuts

Opens the shortcut in the Shortcuts app — tap “Add Shortcut” once. Then use Sync above.

} @else {

Install link not set yet. Build the shortcut once (steps below), Share → Copy iCloud Link, and paste it into shortcutUrl in health.ts.

}

Or build it manually:

  1. 1 Find Health Samples → Sample Type Steps, filter Start Date is today.
  2. 2 Calculate Statistics → operation Sum.
  3. 3 URL action → {{ appUrl }}/?steps=[Statistics] (insert the Statistics variable). The date is filled in by the app.
  4. 4 Open URLs → feed it the URL from step 3 (using the URL action avoids the “rich text” error).
  5. 5 Name the Shortcut exactly SyncHealth.

Each run adds/updates today’s steps; the daily chart builds up over time.
